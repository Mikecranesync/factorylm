# factorylm

**Connect any PLC to Discord and the cloud. Industrial monitoring CLI.**

`factorylm` is a standalone, cross-platform, pip-installable CLI that connects industrial PLCs to a local SQLite database, a web dashboard, Discord, and NVIDIA Cosmos for AI-powered fault analysis.

## Install

```bash
pip install factorylm                    # Core CLI only
pip install 'factorylm[modbus]'          # + Modbus TCP support
pip install 'factorylm[all]'             # Everything (Modbus, EtherNet/IP, S7, Discord, API, Cosmos)
```

## Quick Start

```bash
# 1. Interactive setup wizard
factorylm init

# 2. Test your PLC connection
factorylm connect

# 3. Live tag viewer
factorylm tags

# 4. Start the full pipeline (collector + API + Discord + monitor)
factorylm up
```

## Commands

| Command | Description |
|---------|-------------|
| `factorylm init` | Interactive setup wizard — creates `~/.factorylm/config.toml` |
| `factorylm connect` | Test PLC connection (reads a few registers) |
| `factorylm tags` | Live tag viewer (Rich table, auto-refresh) |
| `factorylm up` | Start full pipeline: collector -> DB -> API -> Discord -> monitor |
| `factorylm down` | Graceful shutdown |
| `factorylm status` | Dashboard showing all subsystem status |
| `factorylm serve` | Start web dashboard only (default port 8001) |
| `factorylm discord` | Start Discord bot only |
| `factorylm collect` | Start tag collector only (PLC -> SQLite) |
| `factorylm version` | Show version |

## Supported PLCs

| Protocol | Driver | Install Extra |
|----------|--------|--------------|
| Modbus TCP | pymodbus | `factorylm[modbus]` |
| EtherNet/IP (Allen-Bradley) | pycomm3 | `factorylm[enip]` |
| S7 (Siemens) | python-snap7 | `factorylm[s7]` |

## Config

Generated by `factorylm init` at `~/.factorylm/config.toml`:

```toml
[plc]
type = "modbus"
host = "192.168.1.100"
port = 502
unit_id = 1
poll_interval = 2.0

[db]
path = "~/.factorylm/tags.db"

[api]
host = "0.0.0.0"
port = 8001

[discord]
token = ""          # or set DISCORD_BOT_TOKEN env var
bot_name = "FactoryLM"

[monitor]
enabled = true
poll_interval = 5.0

[cosmos]
api_key = ""        # or set NVIDIA_COSMOS_API_KEY env var
model = "nvidia/cosmos-reason2-8b"
```

Environment variables override config file values:
- `FACTORYLM_PLC_HOST`, `FACTORYLM_PLC_PORT`, `FACTORYLM_PLC_TYPE`
- `DISCORD_BOT_TOKEN`
- `NVIDIA_COSMOS_API_KEY`

## Architecture

```
PLC (Modbus/EtherNet-IP/S7)
  |
  v
factorylm collect  -->  SQLite (~/.factorylm/tags.db)
  |                          |
  |                          v
  |                   factorylm serve (FastAPI :8001)
  |                          |
  v                          v
factorylm monitor    Web Dashboard (auto-refresh HMI)
  |
  v
NVIDIA Cosmos Reason 2  -->  Incident Analysis
  |
  v
factorylm discord  -->  Discord Slash Commands (/tags, /diagnose, /status)
```
