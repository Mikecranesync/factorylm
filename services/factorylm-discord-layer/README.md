# FactoryLM Discord Layer

Discord communication layer for the FactoryLM agent swarm. Agents post to dedicated Discord channels via rate-limited webhooks, with Telegram format bridging and slash commands for monitoring.

## Architecture

```
                          POST /relay
  ┌───────────┐     {agent, message, format}     ┌──────────────┐
  │  Agents   │ ───────────────────────────────→  │  Relay       │
  │  Tony     │                                   │  Daemon      │
  │  Ultron   │          GET /status              │  :8765       │
  │  Jarvis   │  ←─────────────────────────────── │              │
  │  Hetzner  │                                   │  Rate Limiter│
  └───────────┘                                   │  Queue (500) │
                                                  └──────┬───────┘
  ┌───────────┐                                          │ Webhooks
  │ Telegram  │ ──→ MessageBridge ──→ ↑                  │
  │ Messages  │    (format convert)                      ▼
  └───────────┘                                   ┌──────────────┐
                                                  │  Discord     │
  ┌───────────┐                                   │  Server      │
  │  Discord  │   /relay /status                  │              │
  │  Bot      │   /config show /fleet             │  #tony       │
  │  (slash   │                                   │  #ultron     │
  │  commands)│                                   │  #jarvis     │
  └───────────┘                                   │  #hetzner    │
                                                  │  #alerts     │
                                                  │  #dispatch   │
                                                  │  #plc-live   │
                                                  └──────────────┘
```

## Prerequisites

- Python 3.10+
- Discord bot token (from [Discord Developer Portal](https://discord.com/developers/applications))
- Discord server (guild) with bot added

## Quick Start

```bash
# Clone and install
cd services/factorylm-discord-layer
uv venv .venv && source .venv/bin/activate
uv pip install -e ".[dev]"
uv pip install "discord.py>=2.6"

# Set environment variables
export DISCORD_BOT_TOKEN="your-bot-token"
export DISCORD_GUILD_ID="your-guild-id"

# 1. Run setup wizard (creates channels + webhooks)
factorylm-setup

# 2. Start relay daemon
factorylm-relay

# 3. Start bot (in another terminal)
factorylm-bot
```

## Configuration

Config lives at `~/.factorylm/config.toml` (auto-generated by `factorylm-setup`):

```toml
[discord]
guild_id = 123456789
bot_token_env_var = "DISCORD_BOT_TOKEN"  # reads from this env var

[discord.agents.tony]
name = "Tony"
webhook_url = "https://discord.com/api/webhooks/..."
channel_id = 100
machine = "Mac Mini"
role = "Boss agent"

[discord.agents.ultron]
name = "Ultron"
webhook_url = "https://discord.com/api/webhooks/..."
channel_id = 200
machine = "VPS"
role = "Cloud reasoning"

[telegram]
token_env_var = "TELEGRAM_BOT_TOKEN"
chat_id = 0

[relay]
host = "127.0.0.1"  # or Tailscale IP for remote access
port = 8765
log_level = "INFO"
```

## CLI Commands

| Command | Description |
|---------|-------------|
| `factorylm-setup` | Create Discord categories, channels, and webhooks |
| `factorylm-relay` | Start the HTTP relay daemon on configured host:port |
| `factorylm-bot` | Start the Discord bot with slash commands |

## Slash Commands

| Command | Description |
|---------|-------------|
| `/relay <agent> <message>` | Post a message to an agent's channel via relay |
| `/status` | Show relay daemon uptime, queue depth, agents |
| `/config show` | Ephemeral config overview (hides secrets) |
| `/fleet` | Agent fleet roster |

## Security

- **Webhook URLs are passwords.** Treat them like tokens. They allow anyone to post to your channels.
- **Bot token**: Read from environment variable (named in config), NEVER stored in config files.
- **Relay daemon**: Binds `127.0.0.1` by default. Use a Tailscale IP for remote access, never `0.0.0.0`.
- **Guild commands only**: Slash commands are scoped to a single guild, not registered globally.
- **`/config show` is ephemeral**: Only the caller sees the output. Webhook URLs are excluded.
- **Rate limiter**: Respects Discord's rate limits (5 req/2s per webhook) with automatic 429 retry.
