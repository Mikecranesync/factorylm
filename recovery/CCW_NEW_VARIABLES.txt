HOW TO ADD THESE IN CCW:
  1. Open Project Organizer (left panel)
  2. Expand "Global Variables"
  3. Double-click to open the variable table
  4. For each variable below, click "Add" and fill in:
     - Name (exact spelling, case-sensitive)
     - Data Type
     - Initial Value
  5. Save when done

NEW TIMER INSTANCES TO ADD
================================================================

In CCW, timers are declared as Global Variables with type TON.

  Name              Type    Initial   Purpose
  ────────────────  ──────  ────────  ────────────────────────────
  start_timer       TON     —         3s conveyor ramp-up delay
  stop_timer        TON     —         2s coast-down delay
  uptime_timer      TON     —         1s uptime counter
  vfd_err_timer     TON     —         5s VFD error auto-clear

HOW TO ADD TIMERS:
  - Same as BOOLs/INTs: Add row, Name = "start_timer",
    Data Type = "TON"
  - No initial value needed for TON instances
  - The PT (preset time) is set in the program code
