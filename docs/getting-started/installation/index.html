    Installation Guide¶

    This guide covers the complete installation process for FactoryLM across all supported deployment scenarios.

    System Requirements¶

    Minimum Hardware Requirements¶

    • CPU: Quad-core ARM Cortex-A72 1.5GHz
    • RAM: 4GB (8GB recommended)
    • Storage: 32GB microSD (64GB recommended)
    • Network: Gigabit Ethernet
    • Power: Official Pi 4 Power Supply (5V/3A)
    • CPU: 8+ cores, 3.0GHz+
    • RAM: 32GB+ DDR4
    • GPU: NVIDIA RTX 3080/4080+ with 16GB+ VRAM
    • Storage: 1TB+ NVMe SSD
    • Network: Gigabit Ethernet
    • CPU: Intel i5/i7 or AMD Ryzen 5/7
    • RAM: 16GB+ DDR4
    • Storage: 500GB+ SSD
    • Network: Gigabit Ethernet
    • OS: Ubuntu 22.04 LTS or Debian 12

    Supported Operating Systems¶

    • Raspberry Pi OS (64-bit, based on Debian)
    • Ubuntu 22.04 LTS (x86_64, ARM64)
    • Debian 12 (Bookworm)
    • Red Hat Enterprise Linux 9
    • CentOS Stream 9

    Installation Methods¶

    Choose the installation method that best fits your environment:

    Method 1: Pre-built Image (Recommended)¶

    The fastest way to get started is with our pre-built Raspberry Pi image:

    1. Download the latest image: 

      wget https://github.com/Mikecranesync/factorylm/releases/latest/download/factorylm-pi-image.zip

    2. Flash to SD card: 

      # Using Raspberry Pi Imager (Recommended)
rpi-imager

# Or using dd command (Linux/macOS)
unzip -p factorylm-pi-image.zip | sudo dd of=/dev/sdX bs=4M status=progress

    3. First boot configuration: 

      # SSH into the Pi (default: pi/factorylm)
ssh pi@<pi-ip-address>

# Run setup wizard
sudo factorylm-config

    Method 2: Docker Installation¶

    For x86_64 systems or when you want containerized deployment:

    1. Install Docker and Docker Compose: 

      # Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# Install Docker Compose
sudo apt install docker-compose-plugin

    2. Deploy FactoryLM: 

      git clone https://github.com/Mikecranesync/factorylm.git
cd factorylm
docker compose up -d

    3. Configure via web interface: Open http://<server-ip>:8080 and follow the setup wizard.

    Method 3: Manual Installation¶

    For custom environments or development:

    1. Install prerequisites: 

      # Ubuntu/Debian
sudo apt update && sudo apt install -y \
  python3.10 python3-pip python3-venv \
  git curl build-essential \
  libmodbus-dev libssl-dev

# RHEL/CentOS
sudo dnf install -y \
  python3.10 python3-pip \
  git curl gcc openssl-devel \
  libmodbus-devel

    2. Clone and install: 

      git clone https://github.com/Mikecranesync/factorylm.git
cd factorylm
./scripts/install.sh

    3. Configure environment: 

      sudo systemctl enable factorylm
sudo systemctl start factorylm
factorylm-config

    Environment Configuration¶

    After installation, configure your environment:

    Core Settings¶

    Create and edit the main configuration file:

    sudo nano /etc/factorylm/config.yml

    # FactoryLM Configuration
version: "0.25"

# Deployment scenario (full-stack, air-gapped, budget, security)
deployment: "full-stack"

# Layer configuration
layers:
  layer_0:
    enabled: true
    vector_db: "chroma"
    workflow_engine: true

  layer_1:
    enabled: true
    model: "qwen-0.5b"
    max_memory: "2GB"

  layer_2:
    enabled: false  # Set to true if you have GPU server
    model: "llama-70b"
    gpu_server: "192.168.1.100"

  layer_3:
    enabled: true
    provider: "groq"  # or "claude", "openai"
    api_key: "${GROQ_API_KEY}"

# Industrial protocols
protocols:
  modbus:
    enabled: true
    timeout: 5000

  ethernet_ip:
    enabled: true
    timeout: 5000

  opcua:
    enabled: true
    security_mode: "none"  # or "basic", "signandencrypt"

# User interfaces
interfaces:
  whatsapp:
    enabled: false  # Configure with WhatsApp Business API
    webhook_url: ""
    verify_token: ""

  telegram:
    enabled: true
    bot_token: "${TELEGRAM_BOT_TOKEN}"

  web:
    enabled: true
    port: 8080
    ssl: false

# Logging and monitoring
logging:
  level: "INFO"
  file: "/var/log/factorylm/factorylm.log"
  max_size: "100MB"
  backup_count: 10

monitoring:
  enabled: true
  metrics_port: 9090
  health_check_interval: 30

    API Keys Setup¶

    Set up your API keys for cloud services:

    # Create environment file
sudo nano /etc/factorylm/.env

    # LLM Provider API Keys
GROQ_API_KEY=your-groq-api-key-here
CLAUDE_API_KEY=your-claude-api-key-here
OPENAI_API_KEY=your-openai-api-key-here

# Communication APIs
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
WHATSAPP_WEBHOOK_TOKEN=your-whatsapp-token

# Optional: Monitoring and analytics
LANGFUSE_PUBLIC_KEY=your-langfuse-key
LANGFUSE_SECRET_KEY=your-langfuse-secret

    Industrial Network Configuration¶

    Configure network settings for your industrial environment:

    # Edit network configuration
sudo nano /etc/factorylm/network.yml

    # Industrial Network Configuration
networks:
  production:
    interface: "eth0"
    vlan: 100
    subnet: "192.168.100.0/24"
    gateway: "192.168.100.1"

  control:
    interface: "eth0.200"
    vlan: 200
    subnet: "192.168.200.0/24"
    gateway: "192.168.200.1"

# Security settings
security:
  firewall_enabled: true
  ssh_key_only: true
  fail2ban_enabled: true

  # Industrial protocol ports
  allowed_ports:
    - 502    # Modbus
    - 44818  # EtherNet/IP
    - 4840   # OPC UA

    Deployment Scenarios¶

    A: Full Stack (Internet Available)¶

    # Enable all layers
factorylm config set deployment full-stack
factorylm config set layers.layer_3.enabled true
factorylm restart

    B: Air-Gapped (Defense/ITAR)¶

    # Disable cloud layer, enable GPU server
factorylm config set deployment air-gapped
factorylm config set layers.layer_3.enabled false
factorylm config set layers.layer_2.enabled true
factorylm config set layers.layer_2.gpu_server 192.168.1.100
factorylm restart

    C: Budget (No GPU Server)¶

    # Skip Layer 2, use Pi + Cloud
factorylm config set deployment budget
factorylm config set layers.layer_2.enabled false
factorylm restart

    D: Maximum Security (Pi Only)¶

    # Layer 0 only
factorylm config set deployment security
factorylm config set layers.layer_1.enabled false
factorylm config set layers.layer_2.enabled false
factorylm config set layers.layer_3.enabled false
factorylm restart

    Verification¶

    Verify your installation is working correctly:

    System Health Check¶

    # Check system status
factorylm status

# Run diagnostics
factorylm doctor

# View logs
factorylm logs --tail 50

    Protocol Testing¶

    # Test Modbus connection
factorylm test modbus --host 192.168.1.100 --port 502

# Test EtherNet/IP connection
factorylm test ethernet-ip --host 192.168.1.101

# Test OPC UA connection
factorylm test opcua --endpoint opc.tcp://192.168.1.102:4840

    Interface Testing¶

    # Test Telegram bot
factorylm test telegram

# Test web interface
curl http://localhost:8080/health

# Test API endpoints
curl http://localhost:8080/api/v1/devices

    Troubleshooting¶

    Common Issues¶

    Installation Fails¶

    Insufficient disk space: 

    # Check available space
df -h

# Clean up if needed
sudo apt autoremove
sudo apt autoclean

    Missing dependencies: 

    # Reinstall dependencies
sudo apt update
sudo apt install -f

    Network Connection Issues¶

    Industrial device not responding: 

    # Check network connectivity
ping 192.168.1.100

# Check port accessibility
nmap -p 502 192.168.1.100

# Verify firewall rules
sudo ufw status

    TLS/SSL certificate errors: 

    # Update certificates
sudo apt update && sudo apt install ca-certificates

# Check system time
timedatectl status

    Service Issues¶

    FactoryLM won't start: 

    # Check service status
sudo systemctl status factorylm

# View detailed logs
sudo journalctl -u factorylm -f

# Restart service
sudo systemctl restart factorylm

    High memory usage: 

    # Check memory usage
free -h

# Adjust layer configuration
factorylm config set layers.layer_1.max_memory 1GB

    Log Files¶

    Important log file locations:

    Component Log File
    Main service /var/log/factorylm/factorylm.log
    Industrial protocols /var/log/factorylm/protocols.log
    AI/LLM interactions /var/log/factorylm/llm.log
    Web interface /var/log/factorylm/web.log
    System messages /var/log/syslog
