    Your First Project¶

    This guide will walk you through setting up your first FactoryLM project, connecting to industrial equipment, and performing basic operations.

    Project Overview¶

    In this tutorial, you'll:

    1. Create a new FactoryLM project
    2. Connect to a PLC (Allen-Bradley MicroLogix example)
    3. Configure tag monitoring
    4. Set up alerts and notifications
    5. Test the voice interface
    6. Explore the web dashboard

    Prerequisites¶

    Before starting, ensure you have:

    • FactoryLM installed and running (Installation Guide)
    • Network access to your industrial equipment
    • Equipment documentation (IP address, protocol details)
    • Mobile device with WhatsApp or Telegram

    Step 1: Create a New Project¶

    Projects in FactoryLM organize your equipment, tags, and configurations:

    # Create a new project
factorylm project create "Production Line A" \
  --description "Main production line monitoring" \
  --location "Building 1, Floor 2"

# Switch to the new project
factorylm project use "Production Line A"

    You can also create projects via the web interface at http://<pi-ip>:8080/projects.

    Step 2: Add Your First Device¶

    Let's connect to an Allen-Bradley MicroLogix PLC as our example:

    Discover Devices¶

    First, scan your network for available devices:

    # Scan for EtherNet/IP devices
factorylm scan ethernet-ip --network 192.168.1.0/24

# Scan for Modbus devices
factorylm scan modbus --network 192.168.1.0/24 --ports 502

# Scan for OPC UA servers
factorylm scan opcua --network 192.168.1.0/24

    Add the Device¶

    Based on your scan results, add the device:

    factorylm device add \
  --name "Main PLC" \
  --type "MicroLogix 1400" \
  --protocol ethernet-ip \
  --ip 192.168.1.100 \
  --slot 0 \
  --description "Primary production control PLC"

    factorylm device add \
  --name "Main PLC" \
  --type "Generic PLC" \
  --protocol modbus-tcp \
  --ip 192.168.1.100 \
  --port 502 \
  --unit-id 1 \
  --description "Primary production control PLC"

    factorylm device add \
  --name "SCADA Server" \
  --type "OPC UA Server" \
  --protocol opcua \
  --endpoint "opc.tcp://192.168.1.100:4840" \
  --security-mode none \
  --description "Main SCADA OPC UA server"

    Verify Connection¶

    Test the connection to ensure everything is working:

    # Test device connection
factorylm device test "Main PLC"

# View device information
factorylm device info "Main PLC"

    Expected output: 

    ✅ Connection successful
📊 Device Type: MicroLogix 1400
🌐 IP Address: 192.168.1.100
🔧 Protocol: EtherNet/IP
⚡ Status: Online
📈 Response Time: 23ms

    Step 3: Configure Tag Monitoring¶

    Tags represent data points you want to monitor (temperature, pressure, motor status, etc.):

    Auto-Discovery¶

    Let FactoryLM automatically discover available tags:

    # Discover all available tags
factorylm tags discover "Main PLC"

# Show discovered tags
factorylm tags list "Main PLC"

    Manual Tag Configuration¶

    Add specific tags you want to monitor:

    # Add analog input (temperature)
factorylm tag add \
  --device "Main PLC" \
  --name "Tank_Temperature" \
  --address "N7:0" \
  --type "INT" \
  --unit "°C" \
  --description "Main tank temperature"

# Add digital input (motor status)
factorylm tag add \
  --device "Main PLC" \
  --name "Conveyor_Motor" \
  --address "I:0/0" \
  --type "BOOL" \
  --description "Conveyor motor running status"

# Add analog output (pressure setpoint)
factorylm tag add \
  --device "Main PLC" \
  --name "Pressure_Setpoint" \
  --address "F8:0" \
  --type "REAL" \
  --unit "PSI" \
  --description "System pressure setpoint"

    Tag Groups¶

    Organize related tags into groups:

    # Create tag groups
factorylm tag-group create "Temperature Sensors" \
  --tags "Tank_Temperature,Ambient_Temperature,Motor_Temperature"

factorylm tag-group create "Motor Status" \
  --tags "Conveyor_Motor,Pump_Motor,Fan_Motor"

    Step 4: Set Up Alerts and Notifications¶

    Configure alerts to be notified when values go outside normal ranges:

    Temperature Alert¶

    factorylm alert create \
  --name "High Tank Temperature" \
  --tag "Tank_Temperature" \
  --condition "value > 80" \
  --priority "high" \
  --message "Tank temperature is {{value}}°C - exceeds 80°C limit" \
  --channels "whatsapp,telegram"

    Motor Status Alert¶

    factorylm alert create \
  --name "Conveyor Motor Stopped" \
  --tag "Conveyor_Motor" \
  --condition "value == false" \
  --priority "medium" \
  --message "Conveyor motor has stopped unexpectedly" \
  --channels "telegram"

    Multi-Condition Alert¶

    factorylm alert create \
  --name "System Health Check" \
  --condition "(Tank_Temperature > 85) OR (Conveyor_Motor == false AND Production_Mode == true)" \
  --priority "critical" \
  --message "Critical system issue detected - immediate attention required" \
  --channels "whatsapp,telegram,email"

    Step 5: Test Communication¶

    Now let's test the communication interfaces:

    WhatsApp/Telegram Testing¶

    Send these messages to your FactoryLM bot:

    Basic Queries¶

    What's the status of Main PLC?

    Show me the current tank temperature

    Is the conveyor motor running?

    Advanced Queries¶

    What's the trend for tank temperature over the last hour?

    Are there any alarms on Main PLC?

    Show me all motor statuses

    Voice Interface Testing¶

    If you have voice enabled (Halo glasses or phone):

    1. Call your FactoryLM phone number
    2. Say: "Status of main PLC"
    3. Listen for the response
    4. Try: "What's the tank temperature?"

    Expected Responses¶

    The system should respond with current values:

    Tank Temperature: 72.5°C
    Conveyor Motor: Running ✅
    System Status: Normal
    Last Update: 2 seconds ago

    Step 6: Explore the Web Dashboard¶

    Open your web browser and navigate to http://<pi-ip>:8080:

    Dashboard Overview¶

    The main dashboard shows:

    • Real-time tag values with color-coded status
    • Device health and connection status
    • Active alerts and recent events
    • System performance metrics

    Key Features to Explore¶

    1. Live Data View: Real-time updates every few seconds
    2. Historical Trends: Click any tag to see historical data
    3. Alert Management: View, acknowledge, and configure alerts
    4. Device Configuration: Add/edit devices and tags
    5. System Health: Monitor FactoryLM performance

    Creating Custom Views¶

    Create a custom dashboard for your production line:

    1. Click "Create Dashboard"
    2. Add widgets for your key metrics:
    3. Tank Temperature (Gauge)
    4. Motor Status (LED Indicators)
    5. Pressure Trends (Line Chart)
    6. Alert Summary (Table)
    7. Save as "Production Line A Overview"

    Step 7: Knowledge Base Integration¶

    FactoryLM learns from your interactions. Let's seed it with some knowledge:

    Upload Equipment Documentation¶

    # Upload PLC manual
factorylm knowledge upload \
  --file "MicroLogix_1400_Manual.pdf" \
  --type "equipment-manual" \
  --device "Main PLC"

# Upload troubleshooting guide
factorylm knowledge upload \
  --file "Troubleshooting_Guide.pdf" \
  --type "troubleshooting" \
  --tags "Tank_Temperature,Conveyor_Motor"

    Test Knowledge Integration¶

    Ask questions that require the uploaded documentation:

    What should I do if the tank temperature exceeds 85°C?

    How do I reset fault code F01 on the MicroLogix?

    Verification Checklist¶

    Ensure everything is working correctly:

    • Device shows as "Connected" in status
    • Can read all configured tag values
    • Alerts trigger when conditions are met
    • WhatsApp/Telegram responds to queries
    • Web dashboard displays real-time data
    • Voice interface responds (if enabled)
    • Knowledge base answers equipment questions

    Troubleshooting Common Issues¶

    Device Won't Connect¶

    Check network connectivity: 

    ping 192.168.1.100
nmap -p 502 192.168.1.100

    Verify PLC settings: - EtherNet/IP: Ensure IP address and slot are correct - Modbus: Check unit ID and register addresses - OPC UA: Verify endpoint URL and security settings

    Tags Not Updating¶

    Check tag addresses: 

    factorylm tag test "Tank_Temperature"

    Verify data types: - Ensure tag data type matches PLC data type - Check address format (varies by protocol)

    Alerts Not Firing¶

    Test alert conditions: 

    factorylm alert test "High Tank Temperature"

    Check notification channels: - Verify WhatsApp/Telegram bot tokens - Test communication channel connectivity

    Setting Up Alerts¶

    Configure alerts to notify you when equipment issues are detected:

    1. Navigate to Settings → Alerts
    2. Add notification channels (Email, SMS, Telegram)
    3. Set alert thresholds for each equipment type
    4. Test your configuration

    # Example: Configure Telegram alerts
from factorylm.alerts import TelegramNotifier

notifier = TelegramNotifier(bot_token="YOUR_TOKEN")
notifier.send("Test alert from FactoryLM")
