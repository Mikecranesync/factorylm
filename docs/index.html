    FactoryLM Documentation¶

    Industrial AI Platform — Professional Engineering Documentation

    Welcome to the comprehensive documentation for FactoryLM, an industrial AI platform designed to push intelligence as close to the edge as possible while maintaining professional engineering standards.

    What is FactoryLM?¶

    FactoryLM is a tiered intelligence system that pushes knowledge as close to the edge as possible, using deterministic code for common tasks and escalating to AI only when necessary.

    The One-Liner¶

    FactoryLM is a tiered intelligence system that pushes knowledge as close to the edge as possible, using deterministic code for common tasks and escalating to AI only when necessary.

    Core Philosophy: Intelligence Flows Downward¶

    The goal is NOT to use more AI. The goal is to use LESS AI over time.

    graph LR
    A[Day 1: Query → Cloud AI] --> B[Day 30: Pattern → Workflow]
    B --> C[Day 60: Code → Instant Answer]

    Every trace, every workflow, every observation pushes intelligence DOWN the stack.

    The Four-Layer Architecture¶

    graph TD
    A[Layer 3: Cloud AI<br/>Complex reasoning, novel problems<br/>Response: 1-2s | Cost: $0.01-0.10] --> B[Layer 2: Local GPU<br/>Medium complexity, diagnostics<br/>Response: 2-3s | Cost: Electricity only]
    B --> C[Layer 1: Edge LLM Pi<br/>Simple NL parsing, commands<br/>Response: 0.5-1s | Cost: None]
    C --> D[Layer 0: Code + Knowledge Base<br/>Vector DB, Workflows, Logic Gates<br/>Response: <100ms | Cost: None<br/>🎯 THIS IS THE GOAL]

    Layer 0 is the goal. Everything else is fallback.

    Key Features¶

    ✅ What FactoryLM Does¶

    • Read tag values from PLCs and industrial systems
    • Monitor I/O states in real-time
    • Record fault codes and maintenance history
    • Analyze trends and predict issues
    • Suggest actions based on expert knowledge
    • Voice interaction for hands-free operation

    ❌ What FactoryLM Doesn't Do¶

    • Write to PLCs - Read-only for safety
    • Change setpoints - Diagnostic tool only
    • Start/stop equipment - No control functions
    • Modify programs - Observation only

    Read-Only Constraint

    FactoryLM is a diagnostic tool, not a control system. This eliminates fear, simplifies IT approval, and removes liability.

    Supported Platforms¶

    Industrial Protocols¶

    • Modbus TCP/RTU - Universal compatibility
    • EtherNet/IP - Allen-Bradley systems
    • Siemens S7 - S7-300/400/1200/1500 series
    • OPC UA - Universal standard

    User Interfaces¶

    • Phone - Voice calls and SMS
    • Telegram - Power users and developers
    • Slack - Enterprise teams
    • Halo Glasses - Hands-free factory floor
    • Web Dashboard - Admin and analytics
