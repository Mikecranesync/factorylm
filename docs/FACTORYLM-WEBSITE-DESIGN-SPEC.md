## Executive Summary

## Design System

### Component Library

**Primary:** shadcn/ui + Tailwind CSS v4

**Why:**
- Built-in dark mode support
- Copy-paste components (full customization)
- Industrial/technical aesthetic fits FactoryLM
- Same library can serve marketing + configurator
- Active community, updated Feb 2025

**Installation:**
```bash
npx shadcn@latest init
# Select: New York style, Zinc color, CSS variables: Yes
```

**Key Components:**
- Card - Product tiles, feature cards
- Button - CTAs, actions
- Dialog - Product detail popovers
- Tooltip - Hover hints
- Badge - Level indicators, status
- Progress - Connection status
- Tabs - Navigation sections

## Page Rebuild Plan

### 1. Homepage (/) - Dark Theme Rebuild

**Sections:**

1. **Hero** - "AI for Industrial Maintenance"
   - Dark gradient background
   - Larger, bolder typography
   - Animated product preview or demo video

2. **Features Grid** - "What FactoryLM Does"
   - Dark cards with subtle borders
   - Icon + heading + description
   - Hover state with glow effect

3. **How It Works** - Steps 1-2-3
   - Timeline/stepper design
   - Numbered badges (like /edge/ level badges)
   - Connection lines between steps

4. **CTA Section** - "Ready to fix things faster?"
   - Gradient background
   - Two buttons: "Start Free Trial" + "View Configurator"

5. **Footer** - Unified
   - Links: Home, Blog, Docs, Contact
   - Social links
   - Copyright

### 2. Configurator (/edge/) - USB Enhancement

Keep current layout, add USB-stick design:
- USB-shaped product tiles
- LED connection indicators
- Snap-to-slot interaction
- Product detail popovers

### 3. Blog (/blog/) - Dark Restyle

Changes:
- Dark background
- Card-based article previews
- Reading time badges
- Category tags

### 4. New Pages

**Pricing (/pricing/):**
- 3-tier pricing table (Starter/Pro/Enterprise)
- Feature comparison matrix
- FAQ section
- CTA to configurator

**Documentation (/docs/):**
- Getting started guide
- API reference
- Integration guides
- Dark theme with syntax highlighting
